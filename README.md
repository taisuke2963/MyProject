# バーチャル社員チャット

異なる役割・性格を持つ3人のバーチャル社員(AIエージェント)とチャットできるWebアプリです。

## 登場するバーチャル社員

| 名前 | 役職 | 特徴 |
| --- | --- | --- |
| 佐藤 あかり | 営業担当 | 明るくフレンドリー、提案や商談のアドバイス |
| 田中 健太 | エンジニア | 論理的で簡潔、技術的な質問に強い |
| 鈴木 ゆい | 総務・人事担当 | 丁寧で正確、社内制度や手続きに詳しい |

`employees.js` を編集することで、名前・役職・性格(システムプロンプト)を自由にカスタマイズできます。

## セットアップ

```bash
npm install
cp .env.example .env
# .env に ANTHROPIC_API_KEY を設定
npm start
```

ブラウザで http://localhost:3000 を開き、サイドバーから話したいバーチャル社員を選んでチャットできます。

## 構成

- `server.js` — Express サーバー。`/api/employees` と `/api/chat` を提供
- `employees.js` — バーチャル社員の定義(名前・役職・システムプロンプト)
- `public/` — フロントエンド(チャットUI)
